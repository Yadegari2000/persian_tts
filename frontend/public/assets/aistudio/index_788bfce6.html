⌨️ میانبرهای کیبورد

  • Ctrl + Enterتبدیل پاراگراف فعال
  • Ctrl + Shift + Enterتبدیل همهٔ پاراگراف‌های آماده
  • Ctrl + Z / Yواگرد / انجام مجدد پاراگراف‌ها (خارج از کادر متن)
  • Ctrl + /نمایش/بستن این فهرست
  • Escبستن پنجرهٔ باز

در مک به‌جای Ctrl از ⌘ استفاده کنید. داخل کادرهای متن، Ctrl+Z و Ctrl+Y همان واگرد/انجام مجدد خود مرورگر هستند.
